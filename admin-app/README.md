# Blyp Admin (mobile)

App séparée de Blyp client : tableau simple + alertes push. Connexion = email + mot de passe + code (comme le site).

Le détail / exports / actions souveraines restent sur le site web.

## Utilisation

1. Installer l’APK (build EAS `preview`) sur les téléphones fondateurs.
2. Se connecter avec l’un des emails admin.
3. Accepter les notifications : les alertes arrivent ici, pas dans l’app client.

API : `extra.adminApiBase` dans `app.json`.
